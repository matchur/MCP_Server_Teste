# Estudos de MCP

Este repositório tem dois exemplos independentes:

1. [`campo_mourao`](campo_mourao/) — aula experimental original.
2. [`guia_estudos_mcp`](guia_estudos_mcp/) — próximo passo: tools, resource, prompt e estado salvo em JSON.

O [`python_notebook/arquitetura_mcp.ipynb`](python_notebook/arquitetura_mcp.ipynb) explica a arquitetura MCP e faz chamadas reais ao segundo servidor. Comece pelo README da pasta `guia_estudos_mcp` para instalar e executar.
